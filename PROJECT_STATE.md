## Contracts to preserve

- Three fixed rooms; 2–10 seats including host. Host plays alone immediately; approved late joiners follow the current timeline. Cookie identity, host ACL, epoch/connection guards, command dedupe and revision-guarded atomic queue edits stay authoritative. Reserve 20s, reconnect grace 30s, silent lease 90s, pending TTL 120s, room expiry 24h. Expired host transfers only to the designated live successor, otherwise closes the room. New requests are blocked during host recovery. Clock probes renew leases with 30s SQL coalescing, without heartbeat broadcasts or healthy-socket HTTP polling.
- Public/private rooms. Private summaries hide title/capacity/count/epoch/key; an independent invitation capability lives in the fragment and host DTO only. Rotation cancels pending requests but retains approved members. Approval remains mandatory; this is not E2EE/account authentication.
- Host-only play/pause/seek/Next, one ended transition per generation. Mandatory initial source; approval preempts that modal. Queue ≤50, viewer suggestions ≤3 with 10s cooldown; batch/TXT/static M3U import ≤20 links/16 KiB. Interruption holds freeze the current timeline; ready never auto-plays. Native YouTube/media stays mounted across view/quality/light changes. Drive preview is explicitly unsynchronized. No extraction, transcoding, universal codecs or shared host Premium.
- Local files ≤100 MiB each/250 MiB sender-held total. WebRTC uses public STUN, no TURN; explicit authenticated WS relay ≤25 MiB, 16 KiB chunks/256 KiB window. Full receipt precedes catch-up playback. Sender retains the tab/file; reload requires reselect. No file bytes/history in SQLite/R2. End/Next/remove/leave prune metadata, Blob URLs, handles and transfers.
- Creation-only allowlisted cinema/lounge/rooftop environments (legacy = cinema); cinema/sofa seating, centered 1–3 rows, pre-entry immutable appearance, licensed KayKit rigs and shared geometry/skeleton resources. Eye/orbit, drag/touch/keys/wheel; bounded network head pose. One fixed 8.8×4.95 world screen, depth occlusion and signed-W partial visibility, no automatic dock. Demand rendering stops at rest. Reaction DTOs expose id/kind/time only; actor names never display. HUD chat/approvals/pokes/reactions remain bounded, authenticated and deduplicated; modal focus/inert and reduced motion stay intact. Device Vietnamese TTS uses persisted 0.75–1.25× speed and safe volume duck/restore; no mic/call/clone/NIM production.
