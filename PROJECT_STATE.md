## Contracts

- Three fixed rooms, 2–10 members including host. Cookie identity, approval, host ACL, epoch/connection guards, dedupe and revision CAS stay server-authoritative. Reserve 20s, reconnect grace 30s, silent lease 90s, pending TTL 120s, room TTL 24h. Expired host transfers only to the designated live successor, otherwise closes; new joins block during recovery. Clock probes renew leases with 30s SQL coalescing, no heartbeat broadcasts or healthy-socket HTTP polling.
- Private summaries hide title/capacity/count/epoch/key; invitation capability is in the fragment/host DTO only. Rotation cancels pending, keeps approved members. This is not E2EE/account authentication. No media bytes, recordings or history of played items in SQLite/R2.
- Host-only play/pause/seek/Next and generation-bound ended. Mandatory initial source, approval preempts the starter dialog. Queue ≤50; viewer suggestions ≤3/10s; TXT/static M3U/batch ≤20 links/16 KiB, atomic CAS. Native YouTube/media remains mounted through personal camera/quality/light/Hold changes. Drive preview is explicitly unsynchronized; personal Hold cannot mute it and has a guard. No shared host Premium, stream extraction, DRM bypass or universal codecs.
- Local media ≤100 MiB/file, ≤250 MiB sender-held. Direct WebRTC/public STUN, no TURN; explicit authenticated WS relay ≤25 MiB, 16 KiB chunks/256 KiB window. Full receipt precedes playback. Owner retains file/tab; reload requires reselect. End/Next/remove/leave revoke metadata/Blobs/handles/transfers. Only displayed content can relay; never queued files.
- Creation-only cinema/lounge/rooftop, cinema/sofa seating, centered 1–3 rows; appearance chosen before admission, immutable in-room. Licensed KayKit rigs/shared geometry/skeletons. One 8.8×4.95 world screen, depth occlusion/partial projection, no automatic dock; native player retained. Eye/orbit, drag/touch/keys/wheel and bounded network gaze. One demand renderer, idle/hidden GPU stop, MSAA off, personal Auto/Economy/Detail and reduced motion/fallback.
- Main `sheet` owns chat/queue/people/info/view/actions/readiness/presentation on every viewport. Compact reaction strip has its own dock lane and fixed close, replaces dock controls and coexists with one sheet. ≥44px targets, keyboard/focus/modal inert, viewport keyboard/safe-area layout. Reaction DTO id/kind/time/optional variant only, no actor/name; single event, 3s TTL/5s sender cooldown. Latest chat preview 6s; poke sound recipient-only.
